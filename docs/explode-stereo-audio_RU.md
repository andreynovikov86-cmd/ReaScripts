# Explode Stereo Audio

Автор: **Andrey Novikov (Андрей Новиков)**. Версия **1.0.1**. REAPER **7.46+**. Расширения не требуются.

Скрипт разделяет выбранные стереоайтемы на отдельные физические монофайлы. Левый и правый каналы не суммируются и не подменяются переключением Take channel mode.

## Результат

Одна исходная дорожка становится папкой. Внутри создаётся **ровно одна общая пара** дочерних дорожек для всех обрабатываемых айтемов этой дорожки:

```text
Вокал                 ← прежняя дорожка, теперь папка
  Вокал - L           ← левые каналы всех выбранных файлов, панорама 100% L
  Вокал - R           ← правые каналы всех выбранных файлов, панорама 100% R
```

Если имя исходной дорожки пустое, папка остаётся без имени, а дочерние дорожки называются `L` и `R`. Имя файла для названия дорожек не используется.

Каждая пара полученных L/R айтемов получает собственную группу. Разные фрагменты не объединяются в одну общую группу. Скрипт включает группировку айтемов, если она была выключена; это глобальная настройка REAPER, которая остаётся включённой после Undo.

Айтемы сохраняют положение и длину на таймлайне. Mute и блокировка копируются. Новые дочерние дорожки используют закон панорамирования 0 dB; уровень, панорама, автоматизация, трековые FX и отправки исходной дорожки остаются на папке. Уже существующие дочерние дорожки папки сохраняются.

Исходные обработанные стереоайтемы удаляются **из проекта** после успешного создания всех моноисточников. Исходные файлы на диске не удаляются. Операция отменяется одним Undo; новые файлы на диске сохраняются, чтобы Redo мог их использовать.

## Запуск

- Выделите нужные стереоайтемы на одной или нескольких дорожках и запустите `Explode Stereo Audio (Andrey Novikov)`.
- Если айтемы не выделены, скрипт обрабатывает стереоайтемы на выбранных дорожках. Выбранные айтемы имеют приоритет перед выбранными дорожками.
- Несколько файлов на одной дорожке используют одну общую пару L/R. Каждая другая исходная дорожка получает собственную пару.
- Воспроизведение и запись должны быть остановлены.

Для Melodyne/ARA добавляйте Melodyne на получившиеся дорожки L и R. Трековые плагины исходной дорожки остаются на папке и автоматически на дочерние дорожки не переносятся. Работа конкретной версии Melodyne с результатом отдельно не проверялась; физическая независимость моноисточников проверена.

## Аудиофайлы и ограничения

Используется штатное извлечение каналов REAPER. Новые файлы — **WAV 32-bit float с частотой дискретизации исходника**, в каталоге медиа, выбранном REAPER для проекта. Настройки формата проекта временно устанавливаются для разделения и восстанавливаются после выполнения, в том числе при ошибке. Для исходников с точностью выше 32-bit float точность ограничена форматом результата.

Обрабатываются обычные файловые стереоайтемы с **одним тейком**, **Channel mode: Normal**, на дорожках без fixed/free item lanes. Айтемы с Take FX тоже разделяются: обработка не включается в новые файлы, а цепочка Take FX копируется на каждый получившийся монотейк **в байпасе**. Настройки плагинов сохраняются. Чтобы снова использовать обработку, включите нужные плагины вручную. Для ARA-плагинов может потребоваться новый анализ моноисточника; перенос анализа Melodyne отдельно не проверялся. Моно, MIDI, многоканальные источники и неподходящие айтемы остаются на месте. При наличии пропусков выводится сообщение.

Необработанные/невыбранные айтемы остаются на исходной дорожке, которая становится папкой. При отмене рендера или проверочной ошибке изменения проекта откатываются; уже созданные в ходе попытки файлы не удаляются с диска.

## Установка через ReaPack

Для уже подключённого репозитория `ReaScripts by Andrey Novikov`:

1. **Extensions → ReaPack → Synchronize packages**.
2. **Extensions → ReaPack → Browse packages** → поиск `Explode Stereo Audio`.
3. Отметьте пакет для установки и нажмите **Apply**. Новый пакет обычно нужно установить один раз; дальнейшие версии обновляются при синхронизации.

Адрес репозитория: https://raw.githubusercontent.com/andreynovikov86-cmd/ReaScripts/main/index.xml

Ручная установка: **Actions → Show action list → New action → Load ReaScript** → выберите Lua-файл.

## Проверка

Проверено в отдельном экземпляре REAPER 7.84/macOS-arm64 на искусственном стереофайле, без изменения пользовательского проекта:

- Несколько айтемов на одной дорожке: общие L/R, отдельные группы, сохранение позиции, длины, фейдов, Mute и блокировки.
- Несколько выбранных дорожек, пустые имена, частичное выделение, перекрывающиеся айтемы с одинаковым началом.
- Исходная дорожка-папка, сохранение прежних дочерних дорожек и вложенных закрытий папок.
- Изменённая скорость воспроизведения и смещение начала источника.
- Сохранение трекового ReaEQ; перенос Take FX (JS Volume Adjustment и ReaEQ) на обе стороны в байпасе, с сохранением параметров и без включения обработки в файлы.
- Включение группировки, один Undo/Redo для изменений проекта.
- Ошибка первого извлечения и ошибка после уже созданной пары: восстановление исходников.
- Восстановление настроек записи, копирования/FX и рендера.
- 22 отдельных моно WAV 32-bit float, 48 kHz. Две проверенные пары совпали с соответствующими каналами обрезанного исходника отсчёт в отсчёт, максимальная ошибка 0; сведения L+R нет.
